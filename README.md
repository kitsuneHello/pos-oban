# POSレジ | 文化祭模擬店

学校の文化祭・学園祭の**1団体専用**のPOSレジ（現金決済）Webアプリケーションです。
レジ・キッチン・在庫・ダッシュボードを複数端末でリアルタイムに同期して使えます。

## 主な機能

- レジ会計（POS）: 商品一覧から注文作成、トッピング自由選択・個数指定
- キッチン表示（KDS）: ステータス管理（調理待ち → 調理中 → お渡し可能 → 受取済み）
- 呼び出し: 注文番号の表示（レジ内のタブ）
- 在庫管理: 商品・トッピングの在庫・SOLD OUT・無制限設定、画像登録対応
- ダッシュボード: 売上・注文数の集計
- CSV出力: 注文履歴のCSVエクスポート
- リアルタイム同期: WebSocket により複数端末間で即時同期
- ユーザー名ログイン: ユーザー名 + 共通パスワード認証

## 必要なもの

- Node.js 18 以上（20 LTS 推奨）。express / ws のみ使用。

## インストールと起動

```bash
git clone https://github.com/kitsuneHello/pos-oban.git
cd pos-oban
npm install
npm start
```

`http://localhost:3000` でアクセス。初回起動時はユーザー名 `admin`、パスワード `1234` でログインできます。

## 複数端末の使い方

サーバーを起動したPCに、レジ・キッチンなどの端末からアクセスします。

接続方法の例:
- 同一WiFi / 有線LAN（校内LAN）
- Windows モバイルホットスポット
- ルーターのアクセスポイント
- ngrok（外部ネットワークから）

起動PCのIPアドレス（またはngrok URL）で `http://...:3000` を開きます。

## ユーザー名の追加

`users.txt` に1行1ユーザーで追記します。`#` で始まる行はコメント。**保存と同時に有効**で、再起動不要です。

## データ管理

- 全データ（商品・トッピング・注文・団体名・パスワード）は **`data.json`** に保存されます
- ユーザー名のリストは **`users.txt`** に保存されます
- バックアップ: 両ファイルをコピーするだけ
- 初期化: 在庫画面の設定から「全データを初期化」で商品・トッピング・注文をすべて削除

## セキュリティ

- **信頼できるネットワーク内での利用を前提**としています
- 認証はユーザー名 + 共通パスワード。**初期値の `1234` は必ず変更してください**
- HTTP・共通パスワード方式のため、不特定多数への公開は推奨しません

## 環境変数

| 変更 | デフォルト | 説明 |
|---|---|---|
| `PORT` | `3000` | HTTPリッスンポート |
| `PASSCODE` | `1234` | 共通パスワードを上書き（data.json には保存されない） |

## 技術構成

| 項目 | 内容 |
|---|---|
| サーバー | Node.js + Express |
| リアルタイム同期 | WebSocket（ws） |
| フロントエンド | 素の JavaScript（フレームワーク不使用） |
| データ保存 | `data.json`（同期書き込み） |
