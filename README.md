# POSレジ | 文化祭模擬店

学校の文化祭・学園祭の**1団体専用**のPOSレジ（現金決済）Webアプリケーションです。
レジ・キッチン・呼び出し・在庫・ダッシュボードを複数端末でリアルタイムに同期して使えます。

## 主な機能

- **レジ会計（POS）**: 商品一覧から注文を作成。全トッピングから自由に選択・個数指定
- **キッチン表示（KDS）**: 注文のステータス管理（調理待ち → 調理中 → お渡し可能 → 受取済み）
- **呼び出し掲示板**: お渡し可能・調理中を大きな番号で表示。10秒ごとの自動ページ切替
- **在庫管理**: 商品・トッピングの在庫・SOLD OUT・無制限設定。画像登録（自動圧縮）対応
- **ダッシュボード**: 売上・注文数の集計
- **CSV出力**: 注文履歴をCSVエクスポート
- **リアルタイム同期**: WebSocket により複数端末間で即時同期
- **データ保存**: 追加のデータベース不要。JSONファイルに自動保存

## 必要なもの

- **Node.js 18 以上**（20 LTS 推奨）
  - 確認: `node --version`
- 追加のライブラリは不要です（express / ws のみ使用）

## インストールと起動

```bash
# 1. リポジトリを取得
git clone https://github.com/kitsuneHello/pos-oban.git
cd pos-oban

# 2. 依存パッケージをインストール
npm install

# 3. 起動
npm start
```

起動すると次のメッセージが表示されます:

```
POSレジアプリ起動: http://localhost:3000
```

ブラウザで **http://localhost:3000** を開き、パスコード **1234** を入力して入室してください。

> 初回起動時に `data.json`（注文・在庫などの全データ）が自動的に作成されます。

## 複数端末（レジ・キッチン・呼び出し）での使い方

レジ・キッチン・呼び出し掲示板は別々の端末で同時に使うことができます。

1. すべての端末を **同じ Wi-Fi / ネットワーク** に接続します
2. サーバーを起動したPCの **IPアドレス** を確認します
   - Windows: コマンドプロンプトで `ipconfig`
   - macOS / Linux: ターミナルで `ip a` または `ifconfig`
3. 他の端末のブラウザで `http://<起動PCのIPアドレス>:3000` を開きます
   - 例: `http://192.168.1.10:3000`
4. ファイアウォールでポート **3000** が許可されていることを確認してください

画面はタブで切り替えます（レジ / キッチン / 呼び出し / 在庫 / ダッシュボード）。
ヘッダー右のボタンで上部バーを隠して画面を広く使うこともできます。

## パスコードの変更

環境変数で起動時に上書きできます（データは変更されません）。

```bash
PASSCODE=0000 npm start
```

または `data.json` の `passcode` の値を直接編集します（サーバー停止中に行ってください）。

## ポートの変更

```bash
PORT=8080 npm start
```

## データ管理

- 全データ（商品・トッピング・注文・団体名・パスコード）は **`data.json`** に保存されます
- バックアップ: `data.json` をコピーするだけです
- 初期化: 在庫画面の設定から「全データを初期化」で、商品・トッピング・注文をすべて削除できます

## セキュリティ上の注意

- このアプリは **信頼できるネットワーク内（LAN）での利用を前提** としています
- 認証は共通パスコードのみです。**必ず初期値の `1234` から変更してください**
- HTTP・共通パスコード方式のため、**インターネットへの直接公開は推奨しません**

## 技術構成

| 項目 | 内容 |
| --- | --- |
| サーバー | Node.js + Express |
| リアルタイム同期 | WebSocket（ws） |
| フロントエンド | 素の JavaScript（フレームワーク不使用） |
| データ保存 | `data.json`（同期書き込み） |
