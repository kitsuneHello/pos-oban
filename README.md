# POSレジ | 文化祭模擬店

学校の文化祭・学園祭の**1団体専用**のPOSレジ（現金決済）Webアプリケーションです。
レジ・キッチン・呼び出し・在庫・ダッシュボードを複数端末でリアルタイムに同期して使えます。

## 主な機能

- **レジ会計（POS）**: 商品一覧から注文を作成。全トッピングから自由に選択・個数指定
- **キッチン表示（KDS）**: 注文のステータス管理（調理待ち → 調理中 → お渡し可能 → 受取済み）
- **呼び出し掲示板**: お渡し可能・調理中を大きな番号で表示。10秒ごとの自動ページ切替
- **在庫管理**: 商品・トッピングの在庫・SOLD OUT・無制限設定。画像登録（自動圧縮）対応
- **ダッシュボード**: 売上・注文数の集計
- **CSV出力**: 注文履歴をCSVエクスポート
- **リアルタイム同期**: WebSocket により複数端末間で即時同期
- **ユーザー名ログイン**: ユーザー名（`users.txt`）+ 共通パスワードで入室。ユーザー名はファイルへの追記で追加
- **データ保存**: 追加のデータベース不要。JSONファイルに自動保存

## 必要なもの

- **Node.js 18 以上**（20 LTS 推奨）
  - 確認: `node --version`
- 追加のライブラリは不要です（express / ws のみ使用）

## インストールと起動

```bash
# 1. リポジトリを取得
git clone https://github.com/kitsuneHello/pos-oban.git
cd pos-oban

# 2. 依存パッケージをインストール
npm install

# 3. 起動
npm start
```

起動すると次のメッセージが表示されます:

```
POSレジアプリ起動: http://localhost:3000
```

ブラウザで **http://localhost:3000** を開き、ユーザー名とパスワードを入力してログインしてください。

> 初回起動時はユーザー名 `admin`、パスワード `1234` でログインできます。ユーザーの追加方法は「ユーザー名の追加」を参照してください。
> 初回起動時に `data.json`（注文・在庫などの全データ）が自動的に作成されます。

## 複数端末（レジ・キッチン・呼び出し）での使い方

レジ・キッチン・呼び出し掲示板は別々の端末で同時に使うことができます。

1. すべての端末を **同じ Wi-Fi / ネットワーク** に接続します
2. サーバーを起動したPCの **IPアドレス** を確認します
   - Windows: コマンドプロンプトで `ipconfig`
   - macOS / Linux: ターミナルで `ip a` または `ifconfig`
3. 他の端末のブラウザで `http://<起動PCのIPアドレス>:3000` を開きます
   - 例: `http://192.168.1.10:3000`
4. ファイアウォールでポート **3000** が許可されていることを確認してください

画面はタブで切り替えます（レジ / キッチン / 呼び出し / 在庫 / ダッシュボード）。
ヘッダー右のボタンで上部バーを隠して画面を広く使うこともできます。

## インターネット公開（ngrok）

学校外や別のネットワークから使いたい場合は **ngrok** で公開できます。LAN 内と同様に、HTTP・WebSocket の両方が同じ URL で通ります。

1. [ngrok](https://ngrok.com) にサインアップしてアカウントを作成し、ngrok をインストールします
2. 端末のトークンを設定します

   ```bash
   ngrok config add-authtoken <あなたのトークン>
   ```

3. サーバーを起動してから、ngrok で公開します

   ```bash
   # ターミナル1: アプリを起動
   npm start

   # ターミナル2: ngrok でポート3000を公開
   ngrok http 3000
   ```

4. 表示された `Forwarding` の URL（例: `https://xxxx.ngrok-free.app`）を共有します

> ngrok の無料プランでは 1 つのトンネルのみ、URL は起動のたびに変わります。定番の URL にしたい場合は有料プランが必要です。

## ユーザー名の追加

ログインできるユーザー名は **`users.txt`** で管理します。1行に1つずつ記述し、`#` で始まる行はコメントです。保存すると**再起動なしでその場で有効**になります。

```
admin
たろう
はなこ
```

> サーバーを起動しているPCの `users.txt` を編集してください。GitHub から clone した人は各自のサーバー上のファイルに追記します。

## パスワード（共通）の変更

全ユーザー共通のパスワードです。環境変数で起動時に上書きできます（データは変更されません）。

```bash
PASSCODE=0000 npm start
```

または `data.json` の `passcode` の値を直接編集します（サーバー停止中に行ってください）。

## ポートの変更

```bash
PORT=8080 npm start
```

## データ管理

- 全データ（商品・トッピング・注文・団体名・共通パスワード）は **`data.json`** に保存されます
- ユーザー名のリストは **`users.txt`** に保存されます
- バックアップ: `data.json` と `users.txt` をコピーするだけです
- 初期化: 在庫画面の設定から「全データを初期化」で、商品・トッピング・注文をすべて削除できます

## セキュリティ上の注意

- このアプリは **信頼できるネットワーク内（LAN）での利用を前提** としています
- 認証は「ユーザー名 + 共通パスワード」のみです。**必ず初期値のパスワード `1234` から変更してください**
- ngrok で公開する場合は、ユーザー名とパスワードを知っている人以外アクセスできませんが、**URL が漏れると誰でも試せます**
- HTTP・共通パスワード方式のため、**不特定多数への公開は推奨しません**。知り合い向けに ngrok を使う場合も、使い終わったら ngrok を停止してください
